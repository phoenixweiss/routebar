# Manrope font source

`Manrope-Variable.ttf` is the unchanged variable TrueType font distributed by
the Google Fonts repository under `ofl/manrope`.

Upstream: https://github.com/google/fonts/tree/main/ofl/manrope

The bundled `OFL.txt` applies to the font software. RouteBar's MIT license
continues to apply to the RouteBar source code and original assets.
