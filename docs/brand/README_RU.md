# Айдентика RouteBar

Знак RouteBar показывает небольшой набор явно заданных маршрутов, которые
проходят через границу маршрутизации и меняют полосы. В айдентике намеренно нет
щитов, замков, глобусов и общих VPN-образов: RouteBar управляет узкими host-route,
а не является VPN или самостоятельным продуктом безопасности.

## Основные файлы

| Файл | Применение |
| --- | --- |
| `routebar-lockup.svg` | Основная композиция из знака и переведённого в кривые названия |
| `routebar-mark.svg` | Самостоятельный цветной знак на прозрачном фоне |
| `routebar-app-icon.svg` | Канонический мастер иконки приложения macOS |
| `routebar-app-icon-small.svg` | Оптически увеличенный мастер для слотов ICNS 16 и 32 пикселя |
| `routebar-menu-bar-symbol.svg` | Монохромный эталон значка в строке меню macOS |
| `macos/RouteBar.icns` | Сгенерированная иконка приложения macOS |

Для программ без поддержки SVG приложены PNG. В логотипе используется
переведённое в кривые начертание Manrope Semibold, поэтому шрифт для отображения
не требуется. SVG знака и логотипа адаптируют тёмно-бирюзовую краску к тёмной
цветовой схеме; PNG рассчитаны на светлый фон.

## Использование

- Используйте полную композицию, когда название должно считываться сразу.
- Отдельный знак подходит только там, где RouteBar уже подписан рядом.
- Иконка приложения используется целиком; прозрачный знак не помещается прямо
  в маску иконки macOS.
- Значок строки меню остаётся монохромным template image, чтобы его цветом
  управляла macOS. Полноцветный знак для строки меню не уменьшается.
- Сохраняйте геометрию маршрутов, круглые окончания, соотношение толщин и
  палитру. Не перекрашивайте отдельные маршруты и не добавляйте образы защиты.

После изменения SVG-мастера запустите `script/build-brand-assets`. Обычная
проверка проекта убеждается, что PNG и ICNS по-прежнему соответствуют мастерам.
Каноническая английская версия находится в [README.md](README.md).
